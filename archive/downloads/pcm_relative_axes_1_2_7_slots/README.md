# PCM axes 1, 2, 7 independent relative-teaching slots

모터 고유번호 `3`, `4`, `9`에 대응하는 PCM 내부 축 `1`, `2`, `7`의
독립 상대교시 슬롯 세트다. CSV 하나에는 해당 축 하나의 목표만 들어간다.

축별 슬롯 할당은 다음과 같다.

- 축 1 / 모터 3: 슬롯 11~19
- 축 2 / 모터 4: 슬롯 21~29
- 축 7 / 모터 9: 슬롯 31~39

각 구간의 끝자리별 목표는 동일하다.

- `x1/x2`: +100/-100 deg, 10000 ms
- `x3/x4`: +10/-10 deg, 2000 ms
- `x5/x6`: +1/-1 deg, 2000 ms
- `x7/x8`: +0.1/-0.1 deg, 2000 ms
- `x9`: 0 deg, 10000 ms

CSV의 값은 저장 원점 기준 절대 목표다. 상대교시에서는 슬롯 실행 직전에
실행할 축 하나만 현재 위치를 0도로 저장한 다음 사용한다. 실행 코드의 축 인자도
슬롯과 일치하도록 각각 `axes=(1,)`, `axes=(2,)`, `axes=(7,)`를 사용한다.

슬롯 31~36은 이전 절대교시 시험 파일과 번호가 겹칠 수 있다. PCM에 설치하기
전에 기존 `Motions/motion_11.csv`~`motion_39.csv`를 백업하고 충돌 여부를
확인한다. PCM에는 이 디렉터리의 `motion_*.csv` 27개만 복사하며 README와
manifest는 복사하지 않는다.

파일 생성기는 `tools/generate_relative_axes_1_2_7_slots.py`다.
